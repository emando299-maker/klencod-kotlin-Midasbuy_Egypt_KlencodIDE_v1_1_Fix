# Midasbuy Egypt — مشروع Android/Kotlin لـ KlencodIDE

## ما الذي يقدمه؟
- يفتح موقع Midasbuy Egypt داخل WebView.
- JavaScript وDOM Storage وCookies مفعّلة لدعم تسجيل الدخول وسلة الشراء.
- دعم اختيار الملفات من صفحات الويب.
- دعم تنزيل الملفات عبر DownloadManager.
- زر الرجوع يعيدك للصفحة السابقة داخل الموقع.
- شريط تقدم أثناء تحميل الصفحات.
- الروابط غير HTTP/HTTPS (مثل روابط التطبيقات) تُفتح خارج التطبيق.

## فتح المشروع في KlencodIDE
1. فك ضغط `Midasbuy_Egypt_KlencodIDE.zip`.
2. افتح المجلد الذي يحتوي على `settings.gradle.kts` في KlencodIDE.
3. تأكد من تثبيت Android SDK 34 وJava 17.
4. نفّذ Gradle Sync ثم Build APK.
5. ثبّت APK على Samsung Galaxy A23 بنظام Android 14.

## ملاحظات مهمة
- هذا غلاف WebView وليس تطبيقًا أصليًا تابعًا لـ Tencent أو Midasbuy.
- لا يتم جمع كلمات المرور أو بيانات الدفع بواسطة التطبيق.
- الدفع وتسجيل الدخول يتمان على صفحات Midasbuy ومزودي الدفع أنفسهم.
- بعض مزودي الدفع أو تسجيل الدخول قد يرفضون العمل داخل WebView ويطلبون فتح Chrome؛ هذا قرار من الموقع/مزود الخدمة وليس شيئًا يمكن ضمان تجاوزه.
- الأيقونة المرفقة مؤقتة بتصميم حرف M وألوان ذهبية، وليست الشعار الرسمي المسجل. يمكن استبدالها بملف الشعار الرسمي الذي تملكه أو لديك إذن باستخدامه.
- لم يتم إنتاج APK أو اختباره على جهاز فعلي في هذه الحزمة؛ المشروع يحتاج إلى Build داخل KlencodIDE.
